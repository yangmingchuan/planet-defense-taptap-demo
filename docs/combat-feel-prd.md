# 星球防线：怪潮、火力与音频增量 PRD

日期：2026-09-27。本文覆盖旧文档中的波次数量、初始银币、连发和音频说明；角色编队规则不变。目标是提高战斗密度与命中反馈，不是更换全部角色动画，也不承诺手机恒定帧率。

## 参考与边界

参考用户提供的竞品战斗截图，以及《永远的蔚蓝星球》[官方火箭英雄档案](https://m.chuangyuejoy.com/article/46/)中多发射击、持续集中火力、穿透与爆炸强化的设计。本文未将截图推断为其实际引擎方案，也未逐帧分析实机视频。使用本项目原创角色、生成音频与程序特效，不复制竞品资源。

## 怪潮与经济

- 每关仍十波；第一至九波为 `24 + 波次 * 4`，即28至60只；第十波65只，最后一只是Boss。
- 前五波每批最多3只，后五波最多4只；批间隔 `max(0.38, 0.75 - 波次 * 0.03)` 秒。同屏最多80只，达到上限后等待空位，不丢弃剩余敌人。
- 出生横向范围155至785，纵向240至340（942×1670设计坐标）。保留四类怪物的行走、攻击帧。
- 普通、敏捷单位作为怪潮：原公式生命值乘0.42，原拆墙伤害乘0.10，击杀4银币、10怒气。肉盾、装甲、Boss生命与攻击不变；肉盾/装甲刷新比例降低至0.15/0.12。
- 开局500银币；首波及每波开始仍另加20。召唤20起、每次+8；事件60起、每次+40。死亡立即结算银币；角色最高三级，最多三种职业出征。
- 城墙仍60，星核20。本次通过小怪单体减伤对冲数量增加，不再次翻倍墙血。

## 火力与结算

- 弓箭手、冰法一级/二级两连发，三级三连发，间隔0.08秒。炮手依等级发射1/2/3枚，间隔0.10秒。
- 同一次普通攻击总伤害按弹数均分；护甲扣减和最低伤害也按份额分摊，包括弓箭附带范围伤害、冰法范围伤害。命中或技能关键帧才结算，视觉特效不产生额外伤害。
- 普通攻击选敌半径在职业基础上增加240。狙击弹带亮芯光束拖尾；链雷、狙击命中光束保留0.35秒；炮弹带抛物线尾迹和落点圈。
- 增加命中闪色、冲击碎光、爆炸环、短时连杀显示。既有冰冻大招与冰壳保留。
- 满级弓箭手、炮手、狙击手放大招后获得4秒火力加速，攻速加成+100%，与既有增益共同计算；其他职业保留自己的终极机制。
- 弹道超过160时，新攻击回退为单发并保留该次总伤害，不删除已发射攻击。这是密度降级阈值，不是绝对弹道硬上限。

## 音频与性能

- 新增原创战斗配乐与射击、炮击、冰击、大招四种音效。用户第一次点击后解锁；只在战斗播放配乐，离开战斗停止配乐，静音立即停止全部声音。
- 战斗左侧扬声器按钮控制本会话静音；无持久音量设置。配乐增益0.12、普通音效0.18、大招0.30。
- 音效6个复用声源，射击触发间隔至少0.12秒，其他每类至少0.09秒；声音满载丢弃普通音效，大招可抢占一个声源。
- 程序特效96个、旧粒子64个、飘字48个上限；满载只减少装饰。资源启动时缓存，帧内不读文件。
- 当前仍为NanoVG与Lua对象列表，无宣称图集批处理、空间索引或全面对象池。80怪物是保护阈值，不等于80怪物真机性能验收通过。

## 验证与待验收

- `tests/firepower.lua`：密集投放/80上限回压、伤害分摊（含范围伤害）、延迟命中、特效清理；固定八名一级弓箭手/冰法、不再召唤，随机种子1至5的首波冒烟测试全部进入第二波，墙血40.4至43.9/60，峰值26至27怪。不是所有随机编队十波通关保证。
- `tests/battle-audio.lua`：引擎桩验证点击解锁、声源上限、触发限流、静音、战斗配乐停止。未替代浏览器实际出声检查。
- `tests/squad-combat.lua`：九种混编、270秒模拟、伤害归属和旧功能回归。
- `tests/render-firepower.cjs`：390×844、450×800布局校样；合成65怪物/十名三级守卫测试场景，通过实际Lua绘制函数输出PNG，不是Maker实机截图或真实流程可获得阵容。
- 构建后重点试玩：首关随机编队难度、十波总时长、手机音频解锁、音量混合、后半程同屏帧率。配乐整曲循环，尚未验证循环接缝和真机听感。

## 技术定位

`scripts/BattleTuning.lua`集中怪潮参数；`scripts/CombatFX.lua`负责只读视觉效果；`scripts/BattleAudio.lua`负责资源缓存/声源生命周期与限流；`scripts/main.lua`仍负责攻击与结算。新的完整动画素材必须继续遵守统一尺寸、脚底锚点与特效分层约束。
