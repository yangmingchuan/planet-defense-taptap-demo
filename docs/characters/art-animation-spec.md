# 角色建模、封面与动画制作规范

版本：2026-09-27。状态：制作要求，不代表素材已经生成。与角色档案配套使用。

## 1. 技术路线与“建模”含义

当前是 Lua + NanoVG 的2D游戏，人物是透明PNG，不是实时3D模型。本阶段先做2D造型设定、三视图、分层立绘和序列帧；不为六个角色建立一套成本高昂的实时3D管线。

若以后用Blender制作3D：建议仅作为统一角度的离线渲染源，最终仍输出同尺寸精灵。模型需包含身体、头、左右臂、武器、背包/背架节点；给出武器握点、发射点和脚底原点。需要另评估引擎、骨骼动画和LOD后才能讨论实时3D，不将本规范误当模型已交付。

## 2. 统一画风与轮廓

“浮空前哨守卫”：可爱大头、短四肢、明确轮廓、2-3级赛璐璐明暗；少量机甲配件连接现有叶系弓箭、冰晶法师和自然祝福者。每个角色最多3个主色，粒子颜色不充当唯一身份区分。

| 角色 | 武器轮廓 | 主配色 | 满级轮廓变化 |
|---|---|---|---|
| 炮手 | 粗短炮管 | 珊瑚/白/黄 | 双弹鼓、大炮口 |
| 雷术士 | 分叉音叉杖 | 黄/石墨/白 | 肩部线圈、三叉杖 |
| 狙击手 | 细长导轨枪 | 酒红/白/灰 | 双导轨、分片肩甲 |
| 刃卫 | C形回旋刃 | 草绿/银/珊瑚 | 月轮刃、短翼护肩 |
| 炼金师 | 圆药瓶与罐 | 杏黄/深绿/青柠 | 双室背罐 |
| 引力工程师 | 马蹄磁力器 | 青绿/白/橙 | 展开轨道背架 |

不照搬竞品姓名、服装、立绘、专属武器或技能图标。64像素缩略图下仍应靠武器和轮廓分辨角色；灰度测试也应可区分，不能只换发色。

## 3. 每个角色的完整资产清单

| 资产 | 规格建议 | 用途/验收 |
|---|---|---|
| 三级三视图 | 每级2048×1024，正/侧/背，等比例 | 设计档案，不放入运行时加载 |
| 武器结构图 | 1024×1024，握点/枪口/运动范围 | 三视图与攻击保持同一把武器 |
| 一级立绘 | 1024×1024透明母版 | 输出level-1.png |
| 三级精英立绘 | 1024×1024透明母版 | 输出level-3.png，非一级简单放大 |
| 二级预览 | 两个一级角色组合 | 图鉴与封面可做静态图；战斗仍程序双人绘制 |
| 战斗等级图 | 256×256 RGBA | 统一画布、脚底与实际体积 |
| 封面 | 768×1024，3:4 | 背景与完整角色，UI文字不烘焙进图 |
| 头像 | 256×256 RGBA | 头肩与一部分武器，圆裁和方裁都可识别 |
| 事件图标 | 128×128 RGBA，6个 | 3觉醒+3书籍事件，不画入数值文字 |
| 待机 | I/III各4帧，256×256 | 低频呼吸或眨眼，身体不得漂移 |
| 普攻 | I/III各6帧，256×256 | 双人二级复用一级，不另画两套动作 |
| 终极起手 | III六帧，256×256 | 出手点对应事件，不把伤害画在帧图里 |
| 弹道 | 128×128 RGBA，1-4帧 | 旋转/位移优先交给程序，形状随角色变化 |

## 4. 锚点、朝向与大小

- 战斗母版256×256，建议脚底锚点(128,220)，武器发射点另用归一化坐标记录。这里是新规范，既有DrawDefenderSprite使用旧锚点，接入时必须转换，不能直接替换旧图导致跳位。
- 身体在x=48..208、y=28..220内；武器可延伸至16..240。所有帧共用画布，不按透明边缘逐帧裁剪。
- 面朝战场上方，三分之二背面/侧背面露出轮廓；图鉴正面立绘可单独制作。原型阶段复用正面也必须标记为临时，而非攻击朝向已完成。
- 角色从待机到射击只允许关节动作、少量后坐与衣物运动。尺寸常量、脚底不动，最多2-4设计像素重心偏移；特效不能参与主体包围盒缩放。
- 二级两名单位约为一级显示尺寸的0.76倍，前后错位；点击区域仍是一个格子，不把另一人画到相邻格。三级不是人物数量继续增加，而是一个更精致的英雄。
- 身体轮廓在短屏实机上至少可读；先按实际格子大小预览，不仅检查1024像素大图。

## 5. 动画与命中时间

| 阶段 | 视觉 | 逻辑 |
|---|---|---|
| 预备 | 瞄准/举杖/装填 | 可选目标，不造成伤害 |
| 出手关键帧 | 武器离手或枪口亮起 | 只生成弹道/施法实例 |
| 传播 | 飞行、跳链、去回程 | 更新轨迹，不逐帧重复伤害 |
| 命中关键帧 | 弹头接触、爆炸核心出现 | 扣血、状态、击杀归属 |
| 收尾 | 烟、冰屑、电弧渐隐 | 不再次触发伤害 |

帧索引为1起；总时长与releaseTime记录在角色配置，不全职业硬编码62%。首个攻击帧宜接近待机姿态，避免突然换身高。即使低帧率跳过关键帧，逻辑时间跨越阈值也必须触发且只触发一次。

参考节奏：待机6-8fps；普攻6帧按档案0.36-0.65秒播放；命中特效12-20fps。不能把渲染帧率当动画帧率，也不能每一帧更换图片时同步读磁盘。

## 6. 满级与终极特效语言

- 三级常驻：一处武器灯/局部材质变化，低亮度；不使用十名角色十个持续大光环。
- 觉醒：改变子弹纹样、色条或背架灯，让玩家能区分方向；不重做三套完整人物模型。
- 终极：0.25-0.45秒预警 → 清晰命中峰值 → 快速收尾，总体遮挡尽量控制在1.5秒内；持续区域另按技能持续时间淡化。
- 怒气条始终绑定原格，满怒用一次脉冲提示，不持续全屏闪烁。
- 禁止频繁全屏白闪。震屏默认关闭或可关闭；不能改变UI热区。低特效档仅减少余烟、粒子和残影，绝不删预警/弹头/伤害区域边界。
- 冰壳属于冰法；酸泡属于炼金；雷链属于雷术士；聚怪弧属于工程师。不为了“酷炫”让全部角色都带爆炸、冰冻和闪电。

## 7. 可复用中文提示词

### 造型设定

原创卡通合成塔防角色【角色名】，定位【定位】，主要轮廓【轮廓】，武器【武器】，主色【三主色】，统一大头短腿比例、干净粗轮廓与赛璐璐上色。输出正面、侧面、背面同尺度三视图，武器结构一致，脚底对齐；没有文字、没有水印、没有UI，不参照现有游戏人物。当前等级【I/III】，精英变化为【具体变化】。

### 战斗精灵

使用已确认的【角色版本】造型，面朝战场上方的侧背视角，完整角色及武器，透明背景，固定镜头与256方形画布，脚底锚点一致，主体不超安全边界。姿态【待机/起手/出手/后坐/恢复】，保持头身比例和服装细节；不缩放人物，不画投影到人物层，不画棋盘格，不添加文字，不产生额外手脚。

### 六帧动作参考

同一角色【角色名/等级/参考图版本】，表现【具体攻击动作】，六个连续关键姿态按时间顺序排列，固定镜头、统一身体大小与脚底。第【帧号】帧为武器释放动作；弹道与大范围特效不画入人物层。只作动作设计参考，最终每帧需独立校正和导出，不能把生成的接触图当作已经可直接切图的标准资产。

### 满怒效果

制作【技能名】的二维特效参考，分为【预警、释放、命中、消散】。颜色【色彩】，范围【形状】，中心峰值只出现一次，角色和怪物不在图内，透明背景，无文字、无棋盘格、无全屏白闪。特效形状必须表达真实打击区域，不夸大半径。

## 8. 验收清单

同造型多帧轮廓一致；手数正确；透明通道真实；无白边黑边/棋盘纹；武器不消失闪回；二级不越格；三级可直接认出；封面裁掉文字区仍完整；48/64/96显示像素可辨；所有PNG可由引擎加载；资源清单与许可证齐全。视觉验收必须包含真机攻击录像，静态封面不能代替。
