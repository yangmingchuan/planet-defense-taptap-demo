# 九角色编队试玩版

日期：2026-09-27。状态：本地代码和无引擎回归通过，尚未执行本次 Maker 构建、真机性能验收或远端推送。本文是本轮实现增量，优先于六份角色档案中尚未落地的候选规则。

## 编队

- 入口：底部“守卫”Tab。九名守卫全部供原型测试，无抽卡解锁和养成门槛。
- 点击角色查看 I/II/III 和技能，点击“加入出征”或“撤下守卫”改变阵容。浏览角色不自动改变阵容。
- 最多三种不同职业，允许选择一至三种。允许编辑为空队，但空队不能开战；第四名不会自动挤掉已选角色。
- 默认弓箭手、法师、奶妈。出征配置在本次运行内保留，包括切 Tab、战后回主页、重试；当前无云存档，刷新或重启不保证保留。
- 主页检阅台显示实际选择的队伍。开始关卡时复制编队到当局快照；战斗中不可改编队。
- 兵营在所选职业中等概率召唤一级角色。满格或银币不足不扣钱；不改变当前开局80银币、召唤20起每次+8、事件60起每次+40、十波关卡的代码基线。
- 合成保留旧规则：同级且低于三级可合体；同职业保留职业，异职业从当局阵容中随机出一个职业。二级双人仅一个逻辑单位，三级封顶。
- 书籍只出现出征职业可用事件。新六职业各有普通攻击+10%的专属事件，最多三次，不放大终极；其余职业专属事件和三级互斥觉醒仍属后续提案。现有合到三级赠送一次选项规则保留。

## 新角色战斗

基础伤害、冷却、射程见 `scripts/Roster.lua`，所有数字是待真机平衡的原型参数，不代表商业化完成版。

| 角色 | 普攻 | 满怒终极 |
|---|---|---|
| 爆破炮手 | 固定落点，0.45秒飞行后范围物理伤害，首目标全额、其余55% | 125物理伤害，170半径，最多6目标 |
| 链雷术士 | 首目标8/19/34，后续每跳65%，每段0.08秒，最多2/3/3目标，不重复命中 | 最多6目标，每个75魔法，跳距220 |
| 破甲狙击手 | 优先高护甲、同甲优先近墙；命中无视25%护甲 | 700长直线路径，最近至最远最多3目标，190/95/47.5物理，无视50%护甲 |
| 回旋刃卫 | 去回各0.36秒，路径扫掠，每段最多2/3/3目标；回程50% | 80物理去程、40回程，每段最多3目标 |
| 酸蚀炼金师 | 固定落点药瓶，直伤后每秒2/5/9酸蚀，持续3秒；三级减甲3 | 半径160的酸雾区，持续3秒，每秒最多5目标、18魔法并减甲5；最多2区（含在途预留） |
| 引力工程师 | 引力钉命中减速25%/0.6秒；三级每3次命中且目标仍活着时聚拢 | 55魔法、180半径、最多6目标；40%减速，聚拢最多70 |

普通攻击沿用当前动作时钟，在动作62%处释放；伤害在弹道抵达、路径扫掠或持续伤害tick结算。大招本版点击即发射，未实现档案里的独立蓄力分镜。身体固定站立图、武器光圈和弹道单独绘制。

炮手本版普通半径统一95、最多4目标；炼金师半径统一75、最多3目标；刃卫统一射程430，终极是加强版往返刃。链雷普通跳距统一155。路径碰撞中心阈值统一32。以上与候选档案存在差异，不能宣称完整实现设计版。

酸蚀强覆盖弱，同强度刷新时长但不重置tick；旧来源被合成移除后同强度新施法可接管。酸雾伤害对同一目标有1秒窗口，避免重叠区域叠伤。腐蚀暂共用最强值和剩余时长，并非契约中完整多来源状态栈。

引力聚拢0.25秒完成，只横向或向城墙移动，边界限制在道路内；首领与拆墙怪免疫位移、每只怪0.8秒拉拽冷却。减速仍复用旧版最强比例/时长字段，并非完整多来源回退系统。

既有攻击在施法者合成移除后继续飞行和结算，但不把怒气交给新合成单位。死亡银币只结算一次。新职业终极仍使用原三级击杀蓄怒与领主按钮入口。
