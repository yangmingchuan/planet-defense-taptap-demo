## 原设计落地顺序（历史）

1. 只做炮手：一套三级造型 + 抛物线 + 范围结算，验证区别于弓箭手的手感。
2. 做链雷与狙击手，分别验证分散小怪与高甲敌人的克制关系。
3. 回旋刃需要路径碰撞；酸蚀需要独立状态管理；聚怪需要边界与怪物拥挤验证，后置。
4. 每个角色必须先过独立测试，再与现有三职业进行同经济对照，不一次替换整套游戏。

## 维护流程

设计草案 → 规则评审 → 造型定稿 → 素材制作 → 单角色原型 → 数值测试 → 手机性能与可读性验收 → 小规模进入召唤池。

每个档案记录 design_version、负责人、实现状态、素材状态、最近测试结果。修改现有角色时保留 stable ID，记录与旧版的差异；新增技能不要复用不相干的旧事件 ID。
