# 旧角色动漫改版与专属动画 PRD

版本：2026-09-27 / v2概念设计。与 [分镜图库](anime-v2-gallery.md) 配套；本文件不是已实现变更。七张分镜是动作设计图，没有生成可播放动画。

## 1. 改版目标与保留项

统一到六名新角色的精致Q版动漫方向：干净轮廓、清晰五官、赛璐璐明暗、明确的武器与身体分层。保留旧角色身份，避免看起来像换了一个职业。

| 角色 | 必须保留 | 本轮造型方向 |
|---|---|---|
| 精灵弓箭手 | 橙发、精灵耳、绿叶弓装 | 弓箭更像精灵武器，简化装饰，拉弦轮廓清楚 |
| 冰霜法师 | 白发、蓝眼、冰晶杖 | 去复杂叶帽，短披肩与毛领，菱形冰核，人物不随特效缩放 |
| 花叶祝福者 | 金发、花叶、绿白配色 | 去大浇水壶，短花杖与祝福手势，强调辅助 |
| 小怪兽 | 橄榄绿、红围巾、小牙、短芽 | 清晰表情与挥爪姿态 |
| 肉盾怪 | 紫灰、大前臂、围裙、宽脚 | 慢起慢落、重心下沉 |
| 甲壳怪 | 巨大黄灰甲壳、小脸、短肢 | 小幅弱拳，甲片合拢表现防御 |
| 敏捷怪 | 青绿、尖耳尖发、橙围巾 | 前倾、抓挠、短促制动 |

不改现有属性、召唤概率、怪物数量和大招伤害。新版守卫以三级形态为概念；一级需另做简化版，二级仍是两个一级形象而非两个三级形象。

## 2. 通用动作生产规范

| 资源 | 目标规格 | 当前交付 |
|---|---|---|
| 待机 | 人物层256×256，4帧 | 只有分镜姿态 |
| 普攻 | 人物层256×256，6帧 | 只有四阶段分镜 |
| 守卫大招起手 | 人物层256×256，6帧 | 只有四阶段分镜 |
| 大招效果 | 分层256或512方图，8-12帧 | 只有效果峰值示意 |
| 怪物行走 | 256×256，6帧无缝循环 | 继续用旧版；新版尚未生成 |
| 怪物特殊技 | 人物6帧+独立效果 | 精英设计候选，不进入现有波次 |

分镜只表达关键姿势，不能将四格切开循环冒充完整动画。后续人物统一脚底锚点，所有帧固定身体缩放；大招范围大时只扩大效果层，不缩小角色层。人物层、武器/弹道层、落点层、受击状态层分开制作。

朝向也需分开确认：本轮是便于观察武器的侧前方分镜。最终守卫朝道路上方，怪物朝下方城墙；不是把所有分镜直接朝右加载。固定视角后不能逐帧旋转镜头。

## 3. 普攻时序：与现行逻辑对齐

现有守卫总动作时长 `T=min(0.65,max(0.32,攻击间隔×0.72))`，在0.62T出手。冷却与动作时长不是两个完整攻击间隔叠加。制作六帧时建议关键时间0、0.20T、0.42T、0.62T、0.80T、T；第4帧释放，具体命中由弹道决定。未来改变出手点必须同步程序与测试。

| 守卫 | 待机/蓄力 | 出手 | 命中 | 收势 |
|---|---|---|---|---|
| 弓箭手 | 弓略低；搭箭拉弦，肩不抬高变形 | 0.62T离弦，一枚细箭 | 箭头接触目标，短绿金火花；按当前代码结算 | 手指放松，弓回中位，箭袋不跳位 |
| 冰法 | 杖稳定，冰核从低亮到中亮 | 0.62T射一枚冰弹；人物画布不变 | 冰屑、减速标记；触发冻结时另画敌人冰壳 | 杖回原角度，冰光消退，不换人物大小 |
| 祝福者 | 抬空手，掌心金叶凝聚 | 0.62T送出祝福丝带 | 目标守卫短叶形标记，或墙体修补光 | 手落下，短杖仍由原手持握 |

祝福者不做伤害命中爆炸。普通修墙与祝福继续遵守现有目标选择，不因为设计图同时出现墙与叶就改成每次两种效果全给。

怪物六帧建议关键时间0、0.18T、0.38T、0.58T、0.78T、T；只在0.58T攻击命中一次。

| 怪物 | 当前T/命中点 | 六帧动作拆解 | 视觉强度 |
|---|---|---|---|
| 小怪兽 | 0.85s / 0.493s | 站稳、撤爪、肩扭、挥爪、惯性收爪、回稳 | 单条短弧，当前伤害1 |
| 肉盾 | 1.15s / 0.667s | 下沉、提拳、双拳最高、落拳、低位停顿、起身 | 两点小碎石，当前伤害2 |
| 甲壳 | 1.30s / 0.754s | 小步停稳、伸肘、短拳准备、拳触墙、缩拳、收手 | 极小火花，当前伤害1；分镜火花后续缩小 |
| 敏捷 | 0.65s / 0.377s | 前倾、撤爪、探身、快抓、后撤、回稳 | 一条窄弧，不是多段伤害 |

冻结或死亡打断时不能补发已取消的命中；每次攻击有一次性attackApplied标记。图里的地面冲击只是姿势示意，实际拆墙命中特效应锚定墙前接触点。

## 4. 弓箭手大招：星辉重箭

视觉方案：0.00-0.20s拉满弓，金绿纹样点亮；0.20-0.35s重箭凝成；0.35s离弦；飞行沿现有锁定路径；命中后0.00-0.12s星芒峰值，0.12-0.35s碎光消散。

分层：人物起手、宽箭主体、短尾迹、落点爆裂。箭宽约普通箭2倍；不能用放大整个人物来表示蓄能。分镜峰值贴近弓口，运行时必须移到真实命中点，避免玩家误以为近战攻击。

当前代码按下按钮就生成star_arrow，不等待0.35s。上述蓄力延迟为拟议动画方案，接入时要新增cast状态并统一怒气消耗时点；不能只延迟图片而提前扣敌人血。不改当前150物理及附伤规则，先完成命中同步。

## 5. 冰霜法师大招：绝对零域

核心不是角色变大或变小，而是让道路和被击中敌人结冰。

| 时间（拟议） | 人物层 | 目标区域效果层 |
|---|---|---|
| 0.00-0.20s | 双手握杖，低头蓄力 | 目标点出现淡六角霜纹，非伤害 |
| 0.20-0.35s | 杖尖点地，身体不缩放 | 霜环向边缘扩展，半径与有效范围对应 |
| 0.35s | 保持施法姿态 | 范围一次性结算，冰晶从地面升起 |
| 0.35-0.55s | 杖轻回弹 | 命中的每只敌人各自出现半透明冰壳 |
| 0.55-0.90s | 回待机 | 大范围冰晶淡出，敌人冰壳仍随冻结时长存在 |
| 冻结结束 | 无额外动作 | 独立冰壳0.15s碎裂，不再扣伤害 |

冰壳必须绑定被冻敌人、按敌人大小适配，脸与血条可辨；首领冰壳更短。分镜中的巨大冰罩仅是效果形状说明，不是给法师自己加盾，更不能直接压在角色层上播放。

当前代码是按下按钮即时范围伤害/冻结，然后播扩散冰环；拟议0.35s命中将改变时序，必须连逻辑一起改。沿用68魔法、普通冻结1.8s/Boss0.75s及当前减速规则，不因画面更大而增加伤害/范围。冻结计时从真正生效点起算。

## 6. 祝福者大招：生命超载

拟议0.00-0.20s短杖置胸前、花苞亮起；0.20-0.35s举杖绽放；0.35s统一施加已有修墙与全队祝福；0.35-0.70s叶形光沿城墙和队伍展开；0.70-1.00s花叶落下、角色恢复。

分别制作：人物、全队传播丝带、每名队友头顶叶标、城墙接缝修补光。修补光不是永久绿色墙体，也不是小兵回血数字。墙满血时不画虚假“+8”，队伍增益依旧有效。

当前逻辑立即修墙8、增益至少25%持续7秒；动画延迟仍是提案，需要cast事件同步。队友叶标不能完全遮挡等级和怒气；7秒后状态图标结束，不跟随1秒的起手动画一起消失。

## 7. 怪物特殊技：仅精英变体候选

当前四种普通怪没有怒气或大招。以下只做美术设计，不改敌人属性、数量、护甲或位移；精英触发条件、伤害和冷却另行评审，默认关闭。不能用“视觉改版”名义暗中提高第一关难度。

| 精英候选技能 | 拟议分镜节奏 | 边界 |
|---|---|---|
| 小怪：碎石猛扑 | 0.3s下蹲预警、0.2s短扑、0.15s接触、0.35s回稳 | 单次接触；不能越过墙或直接伤害无HP守卫 |
| 肉盾：重锤震地 | 0.45s蓄拳、0.25s举拳、0.15s砸下、0.45s回稳 | 地面低冲击波；不做全屏眩晕、不默认双倍伤害 |
| 甲壳：合壳固守 | 0.3s缩肢、0.3s合甲、护盾保持时长待定、0.3s展开 | 保持阶段应停止出拳；盾退后恢复，禁止常驻无敌；实际防御参数待定 |
| 敏捷：掠影突刺 | 0.25s明显前倾预警、0.15s短冲、0.1s接触、0.3s制动 | 只一次命中；残影不能生成新实体或绕过墙前位置 |

如将来启用，必须允许冻结打断、死亡取消、控制结束不补发旧技能，确认每波精英数与玩家反应时间，再写入主PRD。

## 8. 后续制作清单

1. 用户确认七名角色的新轮廓，冰法尤其确认去帽后的身份与服装。
2. 独立制作I级/III级守卫站立与六帧攻击；二级复用I级双人。怪物补六帧行走，不能沿用新身材却继续播旧身材。
3. 独立制作3名守卫大招人物起手、弹道、命中和目标状态效果；怪物特殊技留在设计库。
4. 弓箭手实底先处理或重生成透明版；统一画布与脚底，再做白/黑背景边缘检查。此次没有执行抠图或切片。
5. 动画切换录像检查：待机→攻击→收势→待机、冻结打断、拖拽合成、大招后普通攻击，人物不能忽大忽小。
6. 核对所有伤害只在逻辑命中时发生，不随帧图重复。手机同屏怪群下测试，删装饰粒子不能删预警或技能边界。

验收状态：分镜源图与中文提示词已落盘，实际尺寸与透明性已检查；动画循环、锚点、透明边缘、引擎接入与真机表现均未验收。
