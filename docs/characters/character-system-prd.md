# 角色系统 PRD

版本：2026-09-27 / v0.1。状态：新增内容为设计提案，未实现。

## 1. 设计目标

让玩家在缩小的手机战场中，不看名字也能判断“谁在攻击、攻击打到了哪里、为什么值得合成”。差异来自攻击路径、目标选择、伤害节奏和队伍配合，不只是伤害数字与右上角等级。

每个候选至少满足：一个明显轮廓、一把专属武器、一种独立弹道/打击形态、一个明确弱点、三种三级觉醒方向、一个满怒终极。不能同时擅长单体、清群、控场和辅助。

## 2. 现状与提案边界

| 维度 | 当前实现 | 本轮角色提案 |
|---|---|---|
| 职业 | archer/mage/healer | 六名候选独立 ID，尚不入池 |
| 等级 | I/II/III，二级双人、三级精英 | 沿用，不增加四级 |
| 角色生命 | 无，怪物攻击城墙 | 不设计给小兵加血/受伤/复活 |
| 合成 | 同级同职业保持职业，异职业随机 | 同职业不变；新池的随机只能在当局池内 |
| 三级选择 | 每次合成三级弹出免费事件，作用于职业 | 候选角色计划为“本局该职业首次三级，三选一觉醒” |
| 怒气 | 三级击杀25/首领50，满100手动释放；祝福者有助攻来源 | 沿用归属规则，禁止多段命中重复计怒 |
| 局外成长 | 未实现 | 只留接口，不添加角色碎片付费/强制养成 |

首次三级觉醒是新增规则提案，与现有重复弹窗行为不同；落地前必须统一产品基线和迁移测试，不能悄悄改变现有职业。

## 3. 角色定位矩阵

| 角色 | 单体 | 群攻 | 控制/辅助 | 主要克制 | 不擅长 |
|---|---|---|---|---|---|
| 弓箭手（现有） | 高 | 三级扩展 | 无基础控场 | 普通与低甲目标 | 高甲 |
| 冰霜法师（现有） | 中 | 三级扩展 | 减速/冻结 | 敏捷、密集冲线 | 高血孤立目标 |
| 祝福者（现有） | 无 | 无 | 攻击/攻速祝福、修墙 | 长时间攻防 | 独立输出 |
| 爆破炮手 | 中 | 高 | 无硬控 | 密集慢速怪 | 分散敏捷怪 |
| 链雷术士 | 低 | 高 | 默认不眩晕 | 中等间距怪群 | 单首领 |
| 破甲狙击手 | 高 | 低 | 默认不减速 | 甲壳、首领 | 大量低血怪 |
| 回旋刃卫 | 中 | 中高 | 路径覆盖 | 纵深推进队列 | 分散到不同方向的怪 |
| 酸蚀炼金师 | 低 | 中 | 腐蚀减甲 | 长时间存活的装甲群 | 即将撞墙的敏捷怪 |
| 引力工程师 | 低 | 低 | 聚怪、短暂牵制 | 分散普通怪 | 首领与单独清场 |

推荐组合：冰霜+炮手争取落弹命中；酸蚀+弓箭削弱护甲；聚怪+炮手扩大有效命中。不给组合增加隐藏额外伤害，先让基础规则自然协同。

## 4. 召唤池与解锁

- 当前默认池和40%/35%/25%概率保持原样。新增角色不自动混入，避免10格场地被九种职业稀释，难以合成三级。
- 第一阶段开发测试：单个新角色替换弓箭手的测试席位，沿用40%概率；法师35%、祝福者25%。仅用于相同经济条件对照，不是正式配队系统。
- 后续提案：战前选3个不同角色进入当局池，至少2个能造成直接伤害，至多1个纯辅助；引力工程师虽能伤害，不能占用队伍唯一主输出位置。
- 如开放自由配队，三个席位40%/35%/25%须在编队页明确展示，或者另行审批新的概率方案；不能根据“稀有度”暗中改概率。
- 局内不得修改召唤池。跨职业合成结果仍限定在该局池内；不允许合成出未装载资源的角色。
- 解锁先走开发测试开关，后续关卡解锁另立PRD。当前没有付费抽卡、职业品质、保底与碎片解锁。

## 5. 合成、等级与觉醒

1. 一级：一人，基础武器，明确攻击节奏。
2. 二级：两个一级模型同格错位；仍只有一个战斗实体、一份攻击数值与冷却。可交替做动作，不能因为绘制两人重复生成全额伤害。
3. 三级：一个独立精英造型，更醒目的武器与肩部/背部轮廓；初次出现播放约0.6秒合成特效，不遮住邻格。
4. 三名候选觉醒选项互斥，只能选一个；同职业后续三级单位继承该局已选方向。一级/二级不享受觉醒，但可受普通职业事件影响。
5. 觉醒写入 `run.roleAwakenings[roleId]`，结束清空；不是全账号永久解锁，也不改变角色基础素材路径。
6. 满级的常驻外观、普通攻击升级、满怒终极是三层不同表现，普通射击不能每次播放终极级特效。

## 6. 强化事件

- 银币书籍价格和累增规则沿用当前基线；本文件不调整经济。
- 通用事件继续存在；专属事件仅当场上有该职业时入候选池，不给未上场职业开无效选项。
- 每个新职业档案提供3个可购买事件，注明上限。三级觉醒三选一不混入付费书籍池。
- 抽选3个不同且尚未满级事件；不足3个时补可用通用事件。若连一个有效选项都没有，应阻止扣费并解释，不能出现空付费弹窗。
- 事件默认作用于当局该职业全部单位，不能文案写“该角色”但代码全队生效。
- 概率、穿透次数、命中数、半径均有上限；达到上限退出候选池。攻速最终冷却下限暂定0.25秒，需统一现有技能后才能启用。

## 7. 怒气与终极

三级击杀归属单位获得25怒气，首领50，上限100。DoT、跳电、回旋及爆炸共用一次死亡确认；击杀只发一次银币/怒气。二级不攒怒，三级不会因获得材料的既往击杀预充能。

满怒使用现有手动队列，不另加六个技能按钮。主动技能无有效目标不扣怒；施法一旦正式提交，目标消失按技能的固定落点/路径继续执行，不退怒、不重播。

设计中的控制统一约束：首领不受拉拽和击退；新普通技能不额外附带冻结；若未来新增硬控，其首领时长上限需独立验证。不得通过多个引力角色把怪物无限拖离城墙。

## 8. 参数与验证

六份档案的数字是第一轮候选，不是平衡结论。单位：秒、HP、设计坐标像素（942×1670），而非设备物理像素。物理减完整护甲，魔法减半护甲，最低1点，沿用当前基础结算；DoT独立定义，不默认忽略护甲。

对照标准：当前弓箭手三级基础42/0.78≈53.8点每秒，仅是无护甲普通攻击参考，不包含三级附伤、事件、弹道时间和技能。范围/辅助角色单体低于该参考是合理的，必须另测群体总伤害和队伍贡献。

| 测试场景 | 必须记录 |
|---|---|
| 单个55HP普通怪 | 首次命中时间、击杀耗时、空弹/过量伤害 |
| 6只密集普通怪与6只分散怪 | 命中数量、总伤害、目标复用、首杀/清场时间 |
| 135HP/12甲甲壳 | 护甲与破甲计算、减甲覆盖率 |
| 38HP高速敏捷怪 | 固定落点落空率、路径命中、撞墙数量 |
| 第十波580HP首领 | 终极伤害、免疫位移、持续状态时长 |
| 同银币、同事件、同种子十波 | 存活率、城墙剩余HP、三级合成时点、总耗时 |

先跑至少20个固定种子作为冒烟对照，不据此宣称平衡完成；记录均值、范围及异常局。角色输出显著领先时先检查多段重复结算，再调参数。额外做手机100怪+10守卫+多终极压力测试，性能目标与降级见实现契约。

## 9. 非目标与交付门槛

本轮不制作可下载3D模型，不生成整套美术，不改已有战斗。任何新角色上线前必须同时具备：已确认档案、透明战斗素材、攻击时序、唯一命中规则、事件上限、伤害归属测试、手机实机截图与性能记录。仅有一张好看的封面，不算角色完成。
