# 战斗场景背景 V5 中文提示词

用途：用于《星球防线》的竖屏战斗背景。

生成目标：

在 V4 基础上继续压缩底部空间，去掉底部中间的大号星核能量球，加入“星球防御领主”的机甲头像入口，为局外成长线服务。

画面结构：

- 上方：紫黑色陨星裂隙刷新点。
- 中上部：宽阔星尘石板棋盘，道路/战斗区域铺满屏幕主体，带淡淡网格线。
- 下方：横向星核城墙平台，部署格嵌在城墙上方。
- 棋盘边界：中间主城墙为横向部署格，左右两侧各突出 2 个竖向部署格。
- 最下方：紧凑 HUD 区域，中间放一个偏机甲的“星球防御领主”头像/驾驶舱入口，两侧保留干净空间，后续叠加随机事件按钮和兵营召唤按钮。

领主机甲要求：

- Q 版但偏机甲，不是普通小兵。
- 可以有金属肩甲、发光护目镜、蓝色能量线、驾驶舱底座。
- 作为局外成长入口，不占城墙部署格。
- 不要文字、标签或按钮说明。

限制：

- 不要底部大号绿色星核能量球。
- 不要文字、标签、水印。
- 不要角色小兵、怪兽、弹道、金币、UI 按钮。
- 底部只保留可叠加 UI 的紧凑空间。
