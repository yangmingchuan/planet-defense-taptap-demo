# 战斗场景背景 V6 中文提示词

用途：用于《星球防线》的竖屏战斗背景。

生成目标：

在 V5 基础上补齐底部三个可交互入口：左侧事件书籍、中间领主机甲、右侧星港兵营。它们是场景内可点击道具/建筑，不直接画文字标签。

画面结构：

- 上方：紫黑色陨星裂隙刷新点。
- 中上部：宽阔星尘石板棋盘，道路/战斗区域铺满屏幕主体，带淡淡网格线。
- 下方：横向星核城墙平台，部署格嵌在城墙上方。
- 棋盘边界：中间主城墙为横向部署格，左右两侧各突出 2 个竖向部署格。
- 最下方：左侧放打开的发光科技书/战术书，用于弹出随机升级事件；中间放领主机甲头像/驾驶舱入口；右侧放小型星港兵营/召唤舱，用于随机召唤防守角色。

底部入口要求：

- 左侧事件书籍：半打开，页面有蓝绿色星图/符文，不要文字。
- 中间领主机甲：偏机甲头像/驾驶舱，不占部署格。
- 右侧兵营：小型星港门、机甲兵营或传送舱，带能量光，不要士兵。
- 三个入口大小协调，底部紧凑，不留大片空白。

限制：

- 不要文字、标签、水印。
- 不要角色小兵、怪兽、弹道、金币、UI 按钮。
- 不要复制竞品角色或界面。
