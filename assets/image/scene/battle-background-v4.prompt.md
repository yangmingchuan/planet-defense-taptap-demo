# 战斗场景背景 V4 中文提示词

用途：用于《星球防线》的竖屏战斗背景。

生成目标：

在 V3 基础上继续收敛为可直接接 UI 的战斗底图：上方是大面积棋盘战斗区，下方是城墙部署区，最底部留给按钮 HUD。

画面结构：

- 上方：紫黑色陨星裂隙刷新点。
- 中上部：宽阔星尘石板棋盘，道路/战斗区域铺满屏幕主体，带淡淡网格线。
- 下方：横向星核城墙平台，部署格嵌在城墙上方。
- 棋盘边界：中间主城墙为横向部署格，左右两侧各突出 2 个竖向部署格，形成侧翼站位。
- 底部：星核温室和基地建筑缩小，保留世界观符号，同时预留干净 HUD 安全区，用于后续叠加随机事件按钮、兵营召唤按钮、银币和星核耐久。

风格：

- Q 版手绘移动塔防背景。
- 轻微斜俯视。
- 科幻生态混合风格。
- 蓝绿色部署格微光，紫色陨星裂隙对比。

限制：

- 不要文字、标签、水印。
- 不要角色、怪兽、弹道、金币、UI 按钮。
- 底部 HUD 区只留干净地台，不直接画按钮。
- 部署格必须为空，便于后续叠加随机召唤的防守角色。
