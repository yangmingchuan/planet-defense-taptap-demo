# 战斗场景背景 V3 中文提示词

用途：用于《星球防线》的竖屏战斗背景。

生成目标：

修改 V2 背景布局，参考竞品的玩法构图，但不复制其角色、UI、文字、颜色或具体美术。画面需要服务塔防战斗：上方是大面积怪兽行进道路，下方是城墙部署平台。

画面结构：

- 上方：紫黑色陨星裂隙刷新点，顶部入口要宽，避免形成窄路。
- 中上部：大面积灰蓝色星尘石板战场，路面覆盖屏幕主体区域，左右只保留少量岩壁、生态植被和能量管线装饰。
- 下方：横向星核城墙贴近屏幕左右边缘，部署格嵌在城墙上方的平台里，而不是放在城墙外面的路上。
- 城墙平台：主城墙上 6 个发光部署格，左右两边各 1 个贴近屏幕边缘的突出侧翼格，共 8 个可读站位。
- 最下方：星核温室和基地建筑位于城墙后方，作为被保护目标。

风格：

- Q 版手绘移动塔防背景。
- 轻微斜俯视。
- 科幻生态混合风格。
- 蓝绿色部署格微光，紫色陨星裂隙对比。

限制：

- 不要文字、标签、水印。
- 不要角色、怪兽、弹道、金币、UI 按钮。
- 部署格必须为空，便于后续叠加随机召唤的防守角色。
- 路面要宽阔，适合表现一屏幕怪潮。
