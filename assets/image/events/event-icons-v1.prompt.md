1. 全员攻击提升。
2. 攻击爆炸。
3. 攻击速度提升。
4. 城墙加固。
5. 破甲涂层。
6. 合体保留。
7. 技能冷却缩短。
8. 星球意志。
9. 奶妈维修城墙 +1。
10. 奶妈攻速增益。
11. 弓箭多重箭。
12. 冰霜减速。

风格：

- Q 版手绘游戏图标。
- 厚描边，64px 下仍可读。
- 科幻生态塔防风格。

限制：

- 透明 PNG 背景。
- 不要文字、数字、标签、水印。
- 不要 UI 卡片边框。
- 不要现有游戏标志。
