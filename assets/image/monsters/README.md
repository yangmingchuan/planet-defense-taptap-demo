# 星球防线：本地怪兽素材库

本目录保存原创怪兽立绘、中文生成提示词、行走与攻击帧图，以及通用播放配置。

## 怪兽分类

| 文件目录 | 怪兽 | 行走特点 | 攻击特点 |
| --- | --- | --- | --- |
| `basic` | 小怪兽 | 普通交替迈步 | 向前挥爪 |
| `tank` | 肉怪兽 | 沉重迈步，身体轻摆 | 双拳抬起后向下砸 |
| `armored` | 甲壳怪兽 | 低重心，小步慢挪 | 短距离弱小拳击 |
| `agile` | 敏捷怪兽 | 前倾快跑 | 快速前探抓挠 |

## 素材结构

- `monster-atlas-v1.png`：最初的四怪兽设计总览。
- `monster-atlas-v1.prompt.md`：总览图的中文提示词整理版。
- 每种怪兽的 `portrait-v1.png`：从总览原图提取的独立透明立绘。
- 每种怪兽的 `animation-v1.prompt.md`：本次实际使用的中文动画提示词。
- 每种怪兽的 `animation-source-v1.png`：生成的十二帧源图，保留原始尺寸与原有棋盘格背景，供追溯。
- 每种怪兽的 `walk/01.png` 至 `06.png`：六张行走帧。
- 每种怪兽的 `attack/01.png` 至 `06.png`：六张攻击帧。
- 每种怪兽的 `walk-sheet-v1.png`、`attack-sheet-v1.png`：规范化的六帧横向图集。
- 每种怪兽的 `animations-v1.json`：帧尺寸、播放顺序、时间、锚点及命中事件建议。
- `index.html`：本地素材浏览与动画播放页面。
- `contact-sheet-v1.png`：48张处理后帧图的深色底检查总览。
- `export-report-v1.json`：本地切图导出记录。

## 市面上的动画图片怎么切

### 帧动画：每格是一个完整姿势

连续画出同一个角色的多个姿势，再按时间依次显示，就形成动画。素材可以保存为独立 PNG，也可以合成一张精灵图集，在引擎中按行列或坐标读取。[Godot 官方教程](https://docs.godotengine.org/en/stable/tutorials/2d/2d_sprite_animation.html)同时介绍了这两种方式。

本项目本轮采用这种方式。每种怪兽先生成三列四行的源图：前两行是六帧行走，后两行是六帧攻击，均按从左到右、从上到下读取。独立帧导出为统一的256×256透明画布，便于替换和接入。

本轮生成器没有稳定输出真透明背景；经用户明确选择，使用本地程序抠图。由于肉怪兽举拳跨越原始格子边界，实际导出按相连的角色轮廓提取完整姿势，再按四行三列排序，并非机械地等分裁剪。处理保留原图，处理后帧图另存。

### 骨骼动画：每块是一个身体部件

把头、躯干、上臂、前臂、腿等拆成独立图片，绑定骨骼，再通过骨骼的位置和旋转播放动作。这种拆图还需要补画被遮挡的关节区域，不能把整个人物随意切成几块就完成。[Spine 官方入门说明](https://esotericsoftware.com/spine-first-steps)展示了部件图片、骨骼和关键帧之间的关系。

这是制作成本和表现方式的选择；仅凭游戏画面不能断言《永远的蔚蓝星球》具体采用哪种管线。

## 本轮播放建议

以下是原型设计建议，并非行业固定标准。

| 怪兽 | 行走六帧播放速度 | 攻击六帧总时长 | 预期命中位置 |
| --- | --- | --- | --- |
| 小怪兽 | 每秒8帧 | 约0.70秒 | 第4帧开始 |
| 肉怪兽 | 每秒6帧 | 约1.10秒 | 第4帧开始 |
| 甲壳怪兽 | 每秒4帧 | 约1.20秒 | 第4帧开始 |
| 敏捷怪兽 | 每秒12帧 | 约0.48秒 | 第4帧开始 |

行走循环播放；攻击在游戏中播放一次，完成后根据目标是否仍在范围内决定下一次行动。预览页会重复展示攻击，便于检查。

受击伤害只在一次攻击的命中事件触发一次。切换目标、攻击被打断、目标死亡后应取消旧攻击事件。行走图片播放速度与程序中的位移速度是两个参数，不能用角色帧数直接决定移动距离。

## 导入约定与质量边界

- 独立帧为256×256，横向六帧图集为1536×256，背景应有真实透明通道。
- 同一怪兽的所有帧使用同一个缩放系数，不能逐帧拉伸填满画布。
- 导出阶段统一脚底基准；大幅挥臂可能影响自动水平居中，需要在游戏尺寸下复查躯干位置。
- 本轮是AI生成动画初稿，可能存在轮廓、服饰细节和步态连续性的小幅变化。技术上切成六帧不代表美术上已经达到无缝循环。
- JSON 是本素材库的通用描述，并非声称可直接导入 Maker 的专用格式。正式接入时按照项目本地引擎文档编写读取与播放逻辑。
- 本次只制作本地素材，没有构建或发布游戏。

## 复用处理流程

导出工具位于项目的 `scripts/export-monster-frames.cjs`，依赖 Node.js 和 `sharp`。在项目根目录执行 `node scripts/export-monster-frames.cjs --remove-checker`，可以从本轮源图重新导出帧图与JSON；执行前应确保当前环境能找到 `sharp`。此命令会覆盖本轮派生切图，不覆盖生成源图和提示词。

抠图针对本批素材的灰白背景设置，不能保证适用于其他配色。内部封闭缝隙可能残留少量浅色像素，正式素材需进一步检查；不要把这套规则直接批量应用于白色角色。
