# 城墙防御素材 V1 中文提示词

用途：用于《星球防线》的星核城墙状态展示。

生成目标：

生成透明背景的城墙防御素材图，无文字、无 UI。画面为 3 列 x 2 行，共 6 个城墙段：

- 满血城墙。
- 轻微受损城墙。
- 严重受损城墙。
- 维修发光城墙。
- 0 血破损城墙。
- 强化升级城墙。

视觉设定：

- 短矮城墙，适合放在防守角色站位前。
- 白色金属、玻璃墙面、绿色藤蔓、青色能量线、小型星岩细节。
- 受损状态有裂纹、碎石、橙色警示光。
- 维修状态有绿色星露光效。

限制：

- 透明 PNG 背景。
- 不要角色、怪兽、文字、标签、UI 框、水印。
- 每个城墙段居中，留足透明边距，方便切图。
