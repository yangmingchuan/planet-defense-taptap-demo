# 防守角色九宫格 V1 中文提示词

用途：用于《星球防线》原型阶段的防守角色素材。

生成目标：

生成一张透明背景的 2D 手机塔防角色九宫格素材图，不要文字、不要 UI 边框、不要水印。画面为 3 列 x 3 行：

- 第一列：奶妈 / 增益辅助。小型星球生态治疗者，拿浇水壶法杖，暖绿色与奶油色，周围有叶片和增益光效。
- 第二列：弓箭手 / 单体输出。灵活的农场弓箭手，胡萝卜弓、叶片箭袋，橙色头发，绿色披风，瞄准姿态明确。
- 第三列：减速法师 / 控制。冰霜系小法师，白菜帽、冰晶法杖，青蓝和紫色点缀，带冰晶和寒气旋涡。

等级规则：

- 第一行：1 级，造型简单，小体型，装备基础。
- 第二行：2 级，服装、武器、光效明显升级。
- 第三行：3 级，英雄感更强，轮廓更大，带少量金色装饰和更强技能光效。

风格要求：

- 原创 Q 版手绘风格。
- 轻微斜俯视正面，适合竖屏塔防小单位。
- 轮廓清晰，小屏幕也能分辨职业。
- 与现有怪兽素材保持同类移动端塔防美术气质。
- 背景必须为真实透明 PNG alpha，不要棋盘格，不要黑底。

限制：

- 不复制任何现有游戏角色、UI、美术或商标。
- 不出现血腥、恐怖、成人化表达。
- 每个职业、每个等级都要有明显区别。
