# 《星球防线》防守角色素材库 V1

本目录保存三类防守角色的原型素材：奶妈、弓箭手、减速法师。每类角色包含 1/2/3 级形态，可用于兵营随机召唤、拖拽合体和等级 UI 展示。

## 文件结构

| 路径 | 内容 |
|---|---|
| `defender-atlas-v1.png` | 原始九宫格生成图 |
| `defender-atlas-v1.prompt.md` | 中文生成提示词 |
| `defender-contact-sheet-v1.png` | 9 个切图后的总览 |
| `defenders-v1.json` | 职业、等级、切图来源信息 |
| `healer/level-1.png` - `level-3.png` | 奶妈 1-3 级 |
| `archer/level-1.png` - `level-3.png` | 弓箭手 1-3 级 |
| `frost-mage/level-1.png` - `level-3.png` | 减速法师 1-3 级 |
| `*/levels-sheet-v1.png` | 单职业 1-3 级横向图集 |

## 职业定位

| 职业 | 定位 | 原型效果 |
|---|---|---|
| 奶妈 | 增益辅助 | 给周围或当前攻击最高角色叠加攻速/攻击 buff |
| 弓箭手 | 单体输出 | 对路线最前方怪兽发射高频箭矢 |
| 减速法师 | 控制 | 对怪兽造成低伤害并附加减速 |

## 规格

- 单图尺寸：256 x 256 PNG。
- 背景：透明。
- 当前阶段：静态等级形态图，可先用于占位和 UI 验证。
- 后续动画：建议每个职业追加 `idle`、`attack`、`skill` 三组 4-6 帧序列。

## 注意

这批素材是 AI 原型图，适合先验证玩法。正式版本还需要统一体型基准、补充攻击动画、调整小屏幕下的武器和特效可读性。
