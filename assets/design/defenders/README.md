## 评审边界

- 已确认六份文件可解码、有真实Alpha通道、每张包含三种动作；已按生成结果目视检查人物和武器。
- 背景未严格遵守提示词的浅灰要求：返回带透明区和半透明投影、辉光的图，暗色预览器下可能看起来像黑背景。没有进行本地抠图、换底或切帧。
- 部分攻击效果靠近图边，雷电拖尾延伸至右边界；后续独立特效必须重新留足边距。
- 人物视角、脚底位置与武器细节尚未按运行时精灵逐帧校准；引力背架的机械连接还需结构设计复核。
- 这些是造型和动作参考，不是可直接加载的Sprite Sheet；没有生成连续行走循环、六帧攻击、三级觉醒、终极动画、独立封面或3D模型。
- 移动仅供进场/图鉴等演出参考，不修改城墙固定站位规则。
- 保存在 assets/design 而非现有运行时 assets/image/defenders，代码未引用，避免启动时额外加载概念图。
